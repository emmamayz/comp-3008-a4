# comp-3008-a4

Functional interactive interface is ran entirely locally. After extracting files, launch index.html inside a4 to start the task. Task is completed by searching for "software engineering internship in ottawa" for the correct path and "software engineering internship in toronto" for the incorrect path. User can also type in a search that doesn't fall under the permitted searches, but that will produce a no results page that does not have the same location filter quick-changing option.

Permitted searches (case insensitive):
"software engineering internships in ottawa"
"software engineering internships in toronto"
"software engineering internship in ottawa"
"software engineering internship in toronto"
